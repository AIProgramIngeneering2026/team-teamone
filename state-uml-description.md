# Модель состояний заявки (Job State Machine)

## Разрешённые переходы

1. `[*]` → `REQUESTED` — первичное создание заявки на бронь через API.
2. `REQUESTED` → `CONFIRMED` — успешное прохождение всех проверок конвейера Tools.
3. `REQUESTED` → `CANCELLED` — отказ в праве бронирования (нехватка прав, превышение лимитов, занятость места) либо сбой сетевого адаптера расписания.
4. `CONFIRMED` → `USED` — подтверждение явки через вызов API `POST /jobs/{id}/use` в интервале первых 15 минут от старта слота.
5. `CONFIRMED` → `EXPIRED` — автоматический перевод планировщиком при отсутствии чекина через 15 минут после начала слота.
6. `CONFIRMED` → `CANCELLED` — ручная отмена брони владельцем или диспетчером кампуса до начала слота.

---

## Запрещённые переходы и реакция системы

Состояния `USED`, `CANCELLED` и `EXPIRED` являются терминальными (конечными). Выход из них строго запрещен.

При попытке совершить недопустимый переход стейт-машина прерывает выполнение операции, состояние записи в базе данных не изменяется, а клиенту возвращается статус **409 Conflict** с унифицированным форматом ошибки:

| Попытка запрещённого перехода | Описание ситуации | Код ответа | Тело ошибки системы (JSON) |
|---|---|---|---|
| `USED` → `CANCELLED` | Попытка отменить бронь после того, как встреча уже началась | 409 Conflict | `{"error": "INVALID_STATE_TRANSITION", "message": "Нельзя отменить бронь, которая уже используется."}` |
| `EXPIRED` → `USED` | Попытка чекина с опозданием более чем на 15 минут | 409 Conflict | `{"error": "BOOKING_EXPIRED", "message": "Срок бронирования истек из-за неявки."}` |
| `CANCELLED` → `CONFIRMED` | Попытка реактивировать отменённую заявку | 409 Conflict | `{"error": "INVALID_STATE_TRANSITION", "message": "Отмененная заявка не подлежит восстановлению."}` |
| `USED` → `CONFIRMED` | Попытка возврата из терминального статуса использования | 409 Conflict | `{"error": "INVALID_STATE_TRANSITION", "message": "Недопустимый возврат из терминального состояния."}` |
| `REQUESTED` → `USED` | Попытка чекина до завершения работы валидаторов | 409 Conflict | `{"error": "INVALID_STATE_TRANSITION", "message": "Нельзя использовать неподтвержденную бронь."}` |
| `REQUESTED` → `EXPIRED` | Попытка перевода по таймауту заявки, еще проходящей проверку | 409 Conflict | `{"error": "INVALID_STATE_TRANSITION", "message": "Недопустимый переход для статуса REQUESTED."}` |
